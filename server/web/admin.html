PasteLAN Admin

Masuk admin

Password admin = PASTELAN_ADMIN_PASSWORD di server (/etc/pastelan.env).

Tambah perangkat

Link setup sekali pakai: perangkat baru masuk tanpa password. Mac: menu PasteLAN → "Atur server & login…" → tempel link. HP: buka link di browser.

Riwayat clipboard

Isi clipboard hanya di memori server: hilang saat server restart walau hapus otomatis dimatikan. Item terlama dibuang kalau jumlah / memori melebihi batas.
