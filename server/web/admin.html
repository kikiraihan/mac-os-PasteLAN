Lihat semua

    Tambah perangkat

    Mac: menu PasteLAN → Pengaturan → "Atur server & login…", lalu tempel link. HP: buka link di browser.

    Perangkat yang masuk

      Cabut semua perangkat

      Semua Mac dan HP keluar dan harus masuk lagi lewat link setup atau password.

      Riwayat clipboard

      Isi clipboard hanya di memori server dan hilang saat server restart. Kalau batas terlampaui, item terlama dibuang.

      Hapus semua riwayat

      Riwayat clipboard dikosongkan di semua perangkat.

      Password admin

      Setelah diganti, browser lain yang sedang masuk admin akan dikeluarkan. Lupa password baru? Hapus baris "adminPassword" di settings.json (folder data server) lalu restart server: password kembali ke PASTELAN_ADMIN_PASSWORD.

      Masuk dengan password perangkat

      Cara masuk cadangan selain link setup. Password ini dipakai bersama oleh semua perangkat.

      Link setup

      Link setup hanya bisa dipakai sekali dan kedaluwarsa setelah waktu ini.
