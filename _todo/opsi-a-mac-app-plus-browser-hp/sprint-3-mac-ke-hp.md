# Sprint 3 — Alur Mac → HP (real-time) & riwayat

**Tujuan:** setiap kali pengguna copy di Mac, isinya langsung muncul di halaman HP.

## User story

- Sebagai pengguna, saya ⌘C teks di Mac lalu melihatnya muncul di HP dalam ±1 detik, tinggal tekan **Salin**.
- Saya copy screenshot (⌘⌃⇧4) atau gambar di Finder, lalu gambar itu muncul di HP; saya tekan lama untuk menyalin/menyimpan.
- Password dari password manager **tidak** ikut terkirim.
- Saya bisa mematikan pengiriman otomatis dan mengirim manual lewat menu.

## Pemantau clipboard

- macOS tidak punya notifikasi perubahan clipboard → cek `NSPasteboard.general.changeCount` tiap 0,8 detik
  (timer `tolerance` 0,4 dtk, mode `.common` supaya tetap jalan saat menu terbuka). Sangat ringan: hanya membaca satu integer.
- Timer hanya hidup kalau **berbagi aktif** dan **kirim otomatis** menyala.
- Urutan membaca isi:
  1. Ada tipe `org.nspasteboard.ConcealedType` / `TransientType` / `AutoGeneratedType` → **lewati**
  2. File URL dari Finder → kalau ekstensinya gambar, kirim isi file (PNG/JPEG/GIF apa adanya; HEIC/TIFF/dll. diubah ke JPEG supaya bisa tampil di Android). Bukan gambar → lewati
  3. Ada teks **dan** gambar → teks menang, kecuali teksnya hanya sebuah URL (kasus "Copy Image" di browser)
  4. PNG langsung / TIFF → PNG
  5. Teks biasa
- Batas: teks 2 MB, gambar 30 MB

## Riwayat (`ClipStore`)

- 20 item terakhir, hanya di memori; total byte gambar maks 150 MB (yang tertua dibuang)
- Item: `id` (naik terus), `kind` (`text`/`image`), `from` (`mac`/`phone`), `text`/`data`, `mime`, `time`
- Duplikat berturut-turut dari sumber yang sama diabaikan
- `session` acak: berubah saat aplikasi dibuka atau riwayat dihapus → HP otomatis mengosongkan daftarnya

## API

| Endpoint | Hasil |
|---|---|
| `GET /api/items?after=<id>&s=<session>&wait=1` | `{"session","name","items":[…]}`. Kalau belum ada item baru, request **ditahan maks 25 detik** (long-poll). Session beda → semua item dikirim ulang |
| `GET /api/image/<id>?s=<session>&t=<token>` | Byte gambar (`Cache-Control: private, max-age=86400`; URL mengandung session jadi aman di-cache) |

## Halaman HP

- Loop long-poll dengan `AbortController` (batas 35 dtk); saat halaman tampil lagi (`visibilitychange`), polling langsung diulang
- Kartu item terbaru di atas: label 💻 Dari Mac / 📱 Dari HP, jam, isi
- Teks: tombol **Salin** → `navigator.clipboard` kalau secure context, kalau tidak pakai fallback `textarea` + `execCommand('copy')` (kompatibel iOS)
- Teks panjang dipotong + tombol **Selengkapnya**
- Gambar: pratinjau (tekan lama → Salin/Simpan, bawaan iOS/Android) + tombol **Simpan / buka**

## Menu Mac

- **Kirim clipboard Mac otomatis** (centang)
- **Kirim clipboard Mac sekarang** (untuk mode manual, atau kirim ulang)
- Submenu **Riwayat**: 💻/📱 + cuplikan; klik = salin lagi ke clipboard Mac; **Hapus riwayat**
- Baris info: jumlah HP yang sedang terhubung (dari jumlah long-poll aktif)

## Kriteria selesai

- [x] Copy teks di Mac → muncul di HP ≤ 1–2 detik
- [x] Screenshot ke clipboard & gambar dari Finder → muncul di HP
- [x] Isi dari HP tidak memantul jadi item "Dari Mac"
- [x] Restart PasteLAN → HP yang masih terbuka mengosongkan daftar lalu lanjut normal
